# Яндекс Лицей. Задача 5.1: grpc-gateway и Graceful Shutdown

> **Курс:** Специализация «Веб-разработка на Go»
> **Тема:** HTTP-шлюз (grpc-gateway), Makefile, Graceful Shutdown

Ваше новое задание — улучшить существующий gRPC-сервис для управления заказами, который вы разработали в предыдущем задании. Код предыдущего задания можно использовать как основу. 

Теперь сервис должен дополнительно включать **Makefile**, поддержку **grpc-gateway** и механизм **graceful shutdown**.

---

## 🛠 1. Makefile

Напишите `Makefile`, который автоматизирует команды сборки, запуска и генерации кода. 

В `Makefile` должны быть следующие команды:
*   **Генерация кода**: для gRPC и grpc-gateway из `proto`-файла.
*   **Сборка**: компиляция бинарника.
*   **Запуск**: запуск сервера.

---

## 🌐 2. grpc-gateway (HTTP-шлюз)

Добавьте поддержку `grpc-gateway` в свой сервис, чтобы запросы могли обрабатываться через HTTP. 

Убедитесь, что запросы для **всех методов** (`CreateOrder`, `GetOrder`, `UpdateOrder`, `DeleteOrder`, `ListOrders`) могут приходить через HTTP и правильно преобразовываться в gRPC-запросы.

---

## 🛑 3. Graceful Shutdown (Корректное завершение)

Обеспечьте корректное завершение работы сервиса при получении сигнала завершения (`SIGTERM` + `SIGINT`). 

Реализуйте graceful shutdown, чтобы завершить работу сервера без потери активных соединений. 
В завершении программы **ОБЯЗАТЕЛЬНО** выводить сообщение: 
`"Server Stopped"`

---

## ⚠️ Что проверяется системой:
*   Наличие `Makefile` с нужными командами.
*   Поддержка `grpc-gateway` (доступность методов по HTTP).
*   Механизм `graceful shutdown` (корректная обработка сигналов и вывод "Server Stopped").
