# Яндекс Лицей. Задача 7.1: Паттерны отказоустойчивости

> **Курс:** Специализация «Веб-разработка на Go»
> **Тема:** Паттерны отказоустойчивости (Resilience Patterns)

Ваша задача — реализовать 3 паттерна отказоустойчивости в виде Go-программы. Каждый паттерн должен быть отдельной функцией с возможностью протестировать его через автотесты.

Необходимо реализовать: **Retry**, **Timeout**, **Dead Letter Queue**.

---

## 🛠 1. Retry (Повтор с задержкой)

Сервис должен повторять неудачную операцию несколько раз с увеличением времени ожидания (**Exponential Backoff**). Если все попытки исчерпаны, сервис возвращает ошибку.

Напишите функцию `Retry`, принимающую:
*   `operation` — функцию, которая может завершиться ошибкой.
*   `maxRetries` — максимальное количество повторов.
*   `baseDelay` — начальное время ожидания (в миллисекундах).

Реализация должна увеличивать задержку между повторами по формуле `baseDelay * 2^n` (где `n` — номер попытки).

**Пример:**
```go
operation := func() error {
    // что-нибудь делаем
    return nil
}

err := Retry(operation, 5, 100)
if err != nil {
    fmt.Println("Operation failed after retries:", err)
}
```

## ⏱ 2. Timeout (Таймаут)

Сервис должен прерывать выполнение операции, если она занимает слишком много времени.

Напишите функцию `Timeout`, принимающую:
*   `operation` — функцию, выполняющую запрос.
*   `timeout` — максимальное время выполнения (в миллисекундах).

Если `operation` не завершится за заданное время, функция должна вернуть ошибку.

**Пример:**
```go
operation := func() error {
    time.Sleep(2 * time.Second) // эмулируем долгую операцию
    return nil
}

err := Timeout(operation, 1000) // таймаут 1 секунда
if err != nil {
    fmt.Println("Operation timed out:", err)
} else {
    fmt.Println("Operation succeeded")
}
```

## 💀 3. Dead Letter Queue (Очередь мертвых писем)

Сообщения, которые не удалось обработать после нескольких попыток, должны отправляться в специальную очередь для последующей обработки или анализа.

Напишите функцию `ProcessWithDLQ`, которая:
1. Принимает список сообщений и функцию обработки.
2. Сообщения, которые не удалось обработать, записывает в "мёртвую очередь".

Реализуйте хранение "мёртвой очереди" в памяти (например, через слайс или канал).

**Пример:**
```go
messages := []string{"msg1", "msg2", "msg3"}
dlq := NewDeadLetterQueue()

ProcessWithDLQ(messages, func(msg string) error {
    if msg == "msg2" {
        return errors.New("processing failed")
    }
    fmt.Printf("Processed: %s\n", msg)
    return nil
}, dlq)

fmt.Println("Dead Letter Queue:", dlq.GetMessages())
```
