# Яндекс Лицей. Задача 4.1: Конфигурация, Интерсепторы и Makefile

> **Курс:** Специализация «Веб-разработка на Go»
> **Тема:** Работа с конфигурацией (.env), gRPC интерсепторы, Makefile

Ваше новое задание — улучшить существующий gRPC-сервис для управления заказами (CRUD-операции), который вы разработали в предыдущем задании. Код предыдущего задания можно использовать как основу. 

Теперь сервис должен дополнительно включать работу с конфигурациями.

---

## 🛠 1. Конфигурационный модуль
Реализуйте модуль для работы с настройками:
*   Загрузите переменные окружения из файла `.env`.
*   Считайте порт сервера (переменная `GRPC_PORT`) и другие необходимые параметры.

---

## 📝 2. gRPC Интерсептор (Логирование)
Добавьте перехватчик для логирования запросов:
*   Реализуйте интерсептор, который будет логировать входящие запросы и ответы.
*   Зарегистрируйте интерсептор в gRPC-сервере.

---

## 🖥 3. Обновление сервера
Интегрируйте новые модули в основной код:
*   Сервер должен читать порт для запуска из переменной окружения.
*   Свяжите конфигурационный модуль и интерсептор с основным кодом сервера.

---

## 📁 4. Файлы конфигурации
Подготовьте файлы для работы с настройками:
*   Добавьте файл `.env` (он **не должен** попадать в Git, добавьте его в `.gitignore`).
*   Создайте пример конфигурационного файла (`env.example` или `config.example`) с подробным описанием переменных.

---

## 📚 5. Документация
Обновите файл `README.md`:
*   Опишите, как настроить и запустить приложение.
*   Укажите примеры конфигураций и объясните роль каждой переменной окружения.

---

## ⚙️ 6. Makefile
Напишите `Makefile`, который автоматизирует рутинные команды. В нем должны быть следующие цели:
1.  **Генерация кода**: для gRPC из `proto`-файла.
2.  **Сборка**: компиляция бинарника.
3.  **Запуск**: запуск сервера.

---

## ⚠️ Важно:
Решение должно быть оформлено в соответствии с **лучшими практиками разработки** и содержать чистый, понятный код.
