# Яндекс Лицей. Задача 6.1: Контейнеризация и PostgreSQL

> **Курс:** Специализация «Веб-разработка на Go»
> **Тема:** Docker, docker-compose, базы данных

Ваше задание — доработать gRPC-сервис, который вы написали ранее, и упаковать его в контейнеры вместе с PostgreSQL, чтобы получился полноценный проект. 

Нужно, чтобы сервис был готов к запуску в Docker, взаимодействовал с базами данных и мог восстанавливаться после перезапуска (не забываем про правильную настройку graceful shutdown).

---

## 🛠 Что нужно сделать:

### 1. Dockerfile
Напишите `Dockerfile` для вашего gRPC-сервиса (если его еще нет). Убедитесь, что он собирает и запускает сервис правильно, без лишних зависимостей.
*   Вспомните лучшие практики: минимальные образы, правильная структура слоев и т.д.

### 2. docker-compose.yml
Создайте файл `docker-compose.yml`, который поднимет два сервиса:
1.  **Ваш gRPC-сервис** — то, что вы уже написали.
2.  **PostgreSQL** — для хранения информации о заказах.

Убедитесь, что оба сервиса объединены в одну сеть.

### 3. Конфигурация (.env)
Создайте `.env` файл, в который поместите все необходимые переменные окружения: порты, хосты, логины и пароли для PostgreSQL.
*   Настройте `docker-compose.yml`, чтобы он подхватывал переменные из этого `.env` файла.

### 4. Volumes (Хранение данных)
Добавьте в `docker-compose.yml` volumes для хранения данных, чтобы они не терялись при перезапуске контейнеров:
*   `postgres_data` — для хранения данных PostgreSQL.

### 5. Healthcheck (Проверка состояния)
Добавьте `healthcheck` для PostgreSQL, чтобы Docker Compose знал, когда сервис готов к работе. 
*   Эти проверки должны гарантировать, что сервисы действительно запущены и готовы принимать запросы.

### 6. Зависимости (depends_on)
Настройте `docker-compose.yml`, чтобы ваш gRPC-сервис запускался только после того, как PostgreSQL будет готов.
*   Читайте про `depends_on` и `condition: service_healthy`.

---

## ⚠️ Что проверяется системой:
*   Наличие корректного `Dockerfile`.
*   Наличие `docker-compose.yml`.
*   Наличие `healthcheck` для всех сервисов.
*   Наличие `volumes` для хранения данных.
*   Настройка зависимостей сервисов (`depends_on`).

> 💡 *Примечание: В оригинальном тексте задания упоминается Redis, однако по факту тесты проверяют работу только с PostgreSQL. Если вы не добавляли Redis, ничего страшного — достаточно правильно настроить PostgreSQL.*
